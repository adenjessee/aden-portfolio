title: AI agents
---

An agent without a structural view of the repo is a tourist. It opens files by keyword, burns tokens, and reports success in the tone of a senior.

The difference between a junior using an agent and an excellent engineer using one is the loop after the output: did we verify, what did we miss, what would a graph have shown before we spent the money.

I want agents that call tools with evidence tiers, not agents that narrate. Tool calling for a 3D scene is the same idea as tool calling for a codebase. Constrained language. Validated. No arbitrary code.
