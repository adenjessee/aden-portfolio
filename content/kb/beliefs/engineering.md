Software engineering is the work of making a system understandable enough that the next change is safe.

Generation is cheap. Comprehension is not. A pull request that no one can defend is not finished work.

I prefer deterministic methods where they exist. Tests, schemas, graphs, typed boundaries, budgets. A language model is useful after those exist. It is a liability when it is asked to be the source of truth.

I do not treat a greenfield tutorial as proof. Proof is a URL a stranger can open: a live system, a failing test that would have caught the bug, a graph of what the change actually touched.
