I am Aden Jessee, a software engineer and the founder of GridSchool.

I build tools that make repositories understandable. The product that carries that idea is GridSeak: a local, deterministic graph of a codebase that an agent can query instead of guessing. The school that teaches the same idea is GridSchool: a residency for people who can already write a program and still cannot get hired.

I work as an engineer first. The school exists because I kept watching capable graduates ship tutorial clones and then fail a brownfield interview. The graph work exists because language models can generate code faster than they can know what the code means.

I am not a researcher writing papers about agents. I am someone who has to ship systems, keep costs bounded, and stay honest about what the model actually knew.
